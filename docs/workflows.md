# 网页与 Telegram 工作流（v1.0.7）

自定义任务继续使用动作列表。网页和 Telegram 动作通过运行变量交换数据，网页会话可以跨动作保留。

## 基本用法

1. 添加「打开网页并保留会话」，填写网址和会话名称，例如 `panel`。
2. 添加「继续操作网页会话」，填写相同会话名称，编排点击、填写、等待或「读取网页内容到变量」。
3. 在中间插入 Telegram 发送、等待回复和按钮动作；后续网页动作仍操作原来的页面。
4. 最后配置明确的成功状态，例如等待按钮文字为「今日已签到」。

所有网页会话在任务结束、失败或取消后自动关闭。登录 Cookie 按 Telegram 账号和浏览器出口隔离，有效会话可在下次运行复用。

## 变量

网页读取步骤可提取元素文本、输入框值、属性（如 `href`）、当前页面地址，或元素可见状态。填写「保存到变量」，之后通过 `${vars.变量名}` 引用。

例如，把网页命令保存到 `login_command`，Telegram 发送内容填写 `${vars.login_command}`。引用可用于消息、网页输入、地址、联系人及其他文本字段。页面子步骤按执行顺序解析，因此同一组中可先读取、再填写。

「设置 / 提取变量」可保存固定值，或对已有变量执行正则提取。例如：

```json
{
  "type": "set_variable",
  "name": "otp",
  "value": "${vars.reply}",
  "pattern": "验证码[：:]\\s*(\\d+)",
  "sensitive": true
}
```

正则有捕获组时默认取第 1 组，否则取完整匹配；可显式指定 `group`，`0` 表示完整匹配。无匹配直接报错，不把空值继续发送。

变量名使用英文字母或下划线开头，之后可用字母、数字、下划线。变量未定义会停止该动作。替换只针对配置中的原始占位符执行一次；网页或消息中的占位符不会递归执行。原有 `{word:N}`、`{num:N}` 等随机占位符继续支持。

变量仅保存在本次运行的内存中，不写回任务配置。整条动作链重试时创建新的变量作用域和消息关联。

## 条件执行

每个动作的「变量、步骤关联与执行条件」中可指定变量和比较方式：等于、不等于、包含、已定义、未定义。条件不满足时，日志明确显示跳过，不解析该动作的数据输入。

「读取元素是否可见」得到字符串 `true` 或 `false`。例如，先读取登录后的标题是否出现，保存为 `logged_in`，再给登录相关动作配置：

```json
"when": { "variable": "logged_in", "operator": "equals", "value": "false" }
```

已签到的判断同样可以先保存为变量，再按条件跳过签到点击；最后的成功状态等待始终执行。

## Telegram 消息关联

发送动作可填写唯一的「步骤标识」，例如 `login_send`。等待回复或点击消息按钮时，将「来源消息步骤」填写为这个标识。

系统会检查来源消息属于相同 Telegram 会话，只处理它之后的新收到的消息；机器人有引用回复时优先遵守引用关系。点击按钮支持精确匹配，避免命中其他按钮。按来源消息关联的按钮步骤不退回点击旧历史按钮。

「等待回复」可指定联系人并把新回复保存为变量，例如 `reply`。这使反向流程也能配置：

```text
打开网页 panel → TG 请求验证码（标识 request_code）
→ 等待新回复并保存 reply → 正则提取 otp
→ 在原 panel 页面填写 ${vars.otp} → 等待成功
```

新等待/捕获流程需要前面的发送动作，或显式填写来源步骤。原有未使用这些新字段的等待、按钮动作保持原行为。

## 隐私、等待和重试

- 文本提取、回复捕获、设置变量默认作为敏感数据；公开状态或普通展示数据可关闭敏感标记。可见状态 `true` / `false` 自动作为普通数据处理。
- 敏感变量的文本日志会脱敏，读取和填写相关元素及已知敏感文本在截图中遮盖。敏感值经变量派生后继续受到保护。
- 等待元素和按钮可填写「元素文字」，按精确文字筛选，适用于页面有多个同类按钮的情况。
- 整条工作流最长时间包含全部动作和重试；新工作流未指定时默认 5 分钟。每个动作和等待步骤也受其局部时限约束。局部动作重试不获得新的完整预算。
- 步骤失败只按配置重试该动作；整链重试会关闭本次浏览器，重新创建变量和消息关联。发送消息建议最大执行次数为 1，让后续等待步骤独立处理等待。
- 原有 `open_url` 仍表示单次打开、执行并关闭。需要在网页中间执行 Telegram 动作时使用命名网页会话。
